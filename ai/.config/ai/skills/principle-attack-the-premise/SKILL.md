## When
Apply when the task matches this principle's trigger: re-test a shared assumption directly when multiple fixes based on it fail the same gate.

## Strict

## Steps
# Attack the premise

If two or more fixes based on the same assumption fail the same gate, pause before patching again. State the shared assumption explicitly and test it directly against evidence. Change course if it does not hold; do not keep layering fixes on an unverified premise.

## Asks You?
Ask only when applying the principle requires a genuine product choice or conflicts with stated requirements. Otherwise use evidence and the task's constraints.
