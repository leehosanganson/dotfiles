name: frontend-design
description: >-
  Design and implement distinctive, production-ready web interfaces, components,
  or pages with a deliberate visual direction. Use for frontend UI creation or
  substantial redesigns; don't use for backend-only work or small code fixes
  that don't affect the interface.
---

## Workflow

Before implementation, identify the interface's purpose, audience, technical
constraints, and a clear visual direction. Ask about unresolved requirements
that would materially change the design. Make specific choices that fit the
product rather than defaulting to a familiar template.

Implement working, accessible UI using the project's existing framework and
conventions. Refine typography, color, layout, spacing, and interaction details
as a cohesive system. Use motion and decorative effects only when they support
the design and remain usable; respect reduced-motion preferences. Match code
complexity to the visual direction and keep the interface responsive.
