name: principle-web-search
description: Use current external sources when an answer depends on facts that may have changed or cannot be established from local materials.
---

## When
A question depends on current events, recently changed documentation, or external facts not available from local authoritative sources.

## Strict
Search autonomously when current external evidence is needed. Prefer primary sources, verify important claims, and distinguish sourced facts from interpretation.

## Steps
1. Identify the specific external uncertainty.
2. Search authoritative, current sources relevant to that question.
3. Cross-check material claims when practical.
4. Cite sources and date-sensitive caveats in the answer.

## Asks You?
Ask only when the requested external action or source access requires authorization.

## Output
A sourced answer that resolves the uncertainty and clearly states remaining unknowns.

## Best Size
Focused factual research. Use the research workflow for broad multi-source investigations.

## Speed
Prefer a small number of authoritative searches over broad unfocused browsing.

## Edge
For repository-specific behavior, inspect local source first; web search is not a substitute.
