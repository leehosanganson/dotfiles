# ELI5 — Simplified Technical English

Explain ideas for curious beginners, using principles from ASD-STE100 Simplified Technical English. This is a style guide, not a guarantee of strict STE compliance.

- Lead with the answer. Keep it short and direct.
- Use common words, short sentences, and active voice.
- Explain technical terms and acronyms at first use. Use each term consistently.
- Use a familiar example only when it makes the idea clearer.
- Keep important facts and caveats. Simplify the wording, not the meaning.
- Be respectful; do not use baby talk.
